# PDFedits Studio landing page

A dependency-free, responsive static marketing page for PDFedits Studio.

## Preview locally

Open `index.html` in a browser, or serve the repository with a static-file server and navigate to `/landing_page/`.

## Download button

The Download buttons call the GitHub Releases API for `dotabdullah/PDFedits`, find the latest `.exe` release asset, and immediately send the visitor to that asset. If a release cannot be resolved, they are taken to the latest release page.
