## ✨ Features

- **Edit existing PDF text in place** — click and retype, font/style auto-detected
- Add text, images, e-signatures, shapes, highlights, sticky notes, and freehand drawing
- Full page management — add, duplicate, insert, extract, reorder, and rotate pages
- Multiple documents at once (tabs), recent documents, undo/redo, in-document search
- Single-page or continuous-scroll view, with Fit Width / Fit Page / Actual Size zoom
- Export to PDF, PNG, or JPG — print via your system's default PDF viewer

📋 Full feature list, what's shipped vs. planned, and known limitations: **[FEATURES.md](./FEATURES.md)**
📜 Release history: **[CHANGELOG.md](./CHANGELOG.md)**

## 🆓 Free vs. Premium

Everything above is free, with no limits. A handful of advanced features — true redaction, a crop tool, original-font embedding, and file merge/split/watermark/password tools — are planned for a future premium tier rather than free. The reasoning behind each is in [FEATURES.md](./FEATURES.md).
